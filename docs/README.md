# Grey

![logo](icon64.png)

> [!WARNING]
> You should not use this project, this is my own UI framework for public and internal projects. All the inner workings are only kept in my head.

Grey is a minimalistic, blazing fast, disposable, self-container, cross-platform, zero-configuration UI library for C++. C# wrapper available, Python wrapper will be coming soon.

Works on Windows x64, Linux x64, Apple Silicon. Web (Emscripten) version may be coming.
